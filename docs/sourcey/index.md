# Introduction

Thirtyfour is a Selenium / WebDriver library for Rust, for automated website UI testing. It supports all W3C WebDriver and WebElement methods, element queries with explicit waits, action chains, cookies, frames, windows, alerts, shadow DOM, screenshots, and the Chrome DevTools Protocol (CDP) via typed commands.

This site combines a short getting-started guide with a complete, searchable API reference generated from the thirtyfour crate source at a pinned commit. The reference covers the public API: `WebDriver`, `WebElement`, `By` selectors, the query interface, capabilities, actions, cookies, alerts, CDP domains, and WebDriver BiDi.

The project's full guidebook lives at [stevepryde.github.io/thirtyfour](https://stevepryde.github.io/thirtyfour/). The API reference here is generated from source with Sourcey so that it stays in step with the code.
